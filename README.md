One line of office comedy, under 200 characters, for the
[Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232)
bounty on make.fun. A judge model compares jokes two at a time and keeps the
funnier one; the funniest joke takes the whole $2.

`main.ts` writes the joke to `/output/entry.txt`:

> I apologized for the reply-all with a reply-all, and now the apology needs an apology.

Run it with Node 22:

```sh
node main.ts
```
